# keyManage · 密钥生成器

> 一款帮普通人生成 / 找回专属密钥的**纯本地**工具——不需要记住任何东西，也不联网。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## 这是什么

普通人最大的密码痛点不是「记不住」，而是「为了记住而到处复用弱密码」。
本项目用**确定性派生**思路解决：你的设备替你保管一枚专属随机种子，
密钥由 `站名 + 账号` 从种子确定性地派生出来——

- **生成**：站名 + 账号 + 长度 + 字符集选项 → 立即得到密钥，选项自动存档
- **找回**：只需再填一遍 站名 + 账号，复现出与当初完全一致的密钥
- **轮换**：版本号 +1 → 全新密钥，旧密钥作废，用户无感

同样输入永远得到同样密钥；种子不换，换设备只需导入备份。

## 快速开始

| 版本 | 用法 | 适合 |
|---|---|---|
| 网页实验版 | 双击 `keygen.html` | 最快体验，零依赖零安装 |
| Python 初级版 | `py keygen.py`（交互菜单）或 `py keygen.py gen 站名 账号` | 日常命令行使用 |

命令行完整命令：`gen` / `read` / `rotate` / `list` / `export` / `import` / `reset`。

## 工作原理

```
密钥 = 格式化( HMAC-SHA256( 专属种子, "站名|账号|v版本号" ) 的确定性字节流 )
```

- 种子：首次启动用密码学安全随机数生成 256 位，永久固定保存在本机（用户无需记忆）
- 格式化：每个字符从选项字符表按字节流选取，并保证每个选中的字符集至少出现一次
- 全程本地计算，不联网；实现上保证确定性——相同输入必得相同输出

## 安全性说明

- 理论强度按 `长度 × log2(字符集大小)` 实时估算并展示
- 可排除易混淆字符（`0 O 1 l I`），长度 8~64 可调
- 备份文件包含专属种子，请妥善保管；种子丢失 = 全部密钥无法复现
- ⚠️ 实验版将种子存在普通文件 / localStorage 中，尚未进入系统级安全存储，请勿在不可信设备上使用

## 路线图

- [ ] 种子进系统级安全存储（Windows 凭据管理器 / macOS 钥匙串）
- [ ] 首次启动的备份引导（种子丢失 = 全部作废，优先级高）
- [ ] 慢哈希加固（PBKDF2 / scrypt）
- [ ] 多设备同步（加密包）
- [ ] 打包成 exe / 浏览器插件
